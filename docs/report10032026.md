## Sezione rimossa: Risultati

### Motivazione

La sezione **Risultati** (`/risultati`) è stata rimossa dal sito in fase di preparazione alla presentazione. La funzionalità richiede integrazione con un database (risultati live, classifiche, calendario automatico da FIGC-LND) e rappresenta un carico di lavoro significativo lato backend che non è prioritario per il lancio iniziale. Si è deciso di snellire il sito rimuovendo temporaneamente questa sezione per concentrare le risorse sulle parti immediatamente presentabili.

### Modifiche effettuate

| File | Modifica |
|------|----------|
| `src/pages/ResultsPage.tsx` | File eliminato |
| `src/App.tsx` | Rimosso import lazy di `ResultsPage` e rotta `/risultati` |
| `src/data/navigationData.ts` | Rimossa voce `Risultati` dal menu di navigazione principale |
| `src/layout/SiteLayout.tsx` | Rimosso link "Risultati" dalla sezione "Link rapidi" nel footer |
| `src/pages/HomePage.tsx` | Rimosse le due card "Ultimo risultato" e "Classifica" che puntavano a `/risultati` nella strip di accesso rapido |
| `src/components/TeamCard.tsx` | Rimosso il pulsante "Risultati →" che puntava a `/risultati`; rimosso import `Link` non più necessario |
| `src/data/teamsData.ts` | Rimossa la voce `'Risultati'` dall'array `modules` di tutte le squadre agonistiche (1a Categoria, 3a Categoria, Juniores Regionali, Allievi, Giovanissimi) |

### Note

La sezione potrà essere reintrodotta in futuro quando sarà disponibile l'infrastruttura backend per i dati di risultati, classifiche e calendari gare.
